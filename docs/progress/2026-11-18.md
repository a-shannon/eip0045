# EIP-0045 dev update — three recursive proofs you can replay

The [first 3.1.0 demo](../../demos/risc0-3.1.0/README.md) verified a single lift. We've now published three real recursive receipts for the same Ergo statement. One joins two segments, one discharges an assumption under an explicit control root, and one discharges a zero-root assumption before joining. The last two use the original lift as their assumption receipt.

From a checkout, run:

```sh
python3 demos/risc0-3.1.0/recursive/verify.py
```

Rust verifies the saved parents and reconstructs each graph. Rust and the JVM both accept all three final proofs. Change one bit in the expected payload and both reject each unchanged proof.

We also put the earlier **lift-15** receipt into a local Ergo transaction with a token payment, change and a miner fee. It serialized to **223,010 bytes**, leaving **39,134 bytes** below the proposed 256 KiB admission limit. On a Ryzen 9 9950X3D, median warm verification time was **15.4 ms** for the proof. A separate local node harness decoded and validated the full transaction in **21.4 ms** at the median with the input box in memory. Those measurements apply to the lift-15 fixture.

The [recursive replay guide](../../demos/risc0-3.1.0/recursive/README.md) includes the three seal hashes and explains how to distinguish the two joins. Work continues on the full B4 corpus and production pricing.
