# EIP-0045 development checkpoint — 4 November 2026

The local validation work now includes a Rust/JVM differential result and a
working native publisher for two additional terminal-metadata test inputs.

In the [29 October checkpoint](2026-10-29.md), input preparation stopped at its
600-second limit before a neutral test input existed. A subsequent bounded
run completed preparation, replayed the retained case-8 proof and published
the terminal-metadata kind test input. Its selector completed in 217.89
seconds; the nested `verify_stark` call took 27 milliseconds in that run.
These are local observations, not a consensus cost schedule or resource guarantee.

Rust and JVM then read separate copies of the same neutral input. Both
rejected the changed metadata kind at `terminal-metadata-binding`, with
byte-identical 448-byte result records. The captured pair received independent
review. A separate supplied-byte QA step checked the result against the
negative-plan recipe after both verifier processes had finished.

The current publisher has now replayed the retained case-8 input and produced
two more neutral roots: one changes the metadata parameter, the other changes
the control ID. One consuming publication call created both roots and their
identity sidecars. Twenty payload files were captured and preserved in two
host copies. Independent checks rederived their canonical descriptors,
512-byte subjects, seven contexts per root and their source/recipe/identity
relationships. No new proof was generated.

This closes the two-input production and capture milestone. Rust/JVM consumer
observations and expected-result QA for these new inputs remain the next
step. Their production does not extend the completed kind-test pilot into a
three-input differential result.

The local publication API also passed targeted ownership and file-publication
checks, including a compiler refusal of a second use of a consumed publication
handle. The additional publisher changes described here have not yet been
added to the source published in this repository. This checkpoint reports
local results; it is not a complete public reproduction package for them.
