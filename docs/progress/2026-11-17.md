# A RISC Zero 3.1.0 receipt that Rust and the JVM both verify

The November 6 preview gave developers local library checks and a catalogue
of native tests. The new [lift-15 demo](../../demos/risc0-3.1.0/README.md)
lets them try a real proof using the corrected RISC Zero 3.1.0 circuits.

One command verifies the same proof in stock Rust and in an independent Scala
verifier on the JVM. Both accept the original Ergo statement. Change one bit
in the expected application payload and both reject the unchanged proof.
The archive includes the receipt and raw seal, so replay requires no prover.
The guest source and generation recipe are available for anyone who wants
to build the guest and produce a fresh proof.

This checkpoint covers a single `lift-po2-15` case with a candidate profile.
The next engineering questions are the rest of the conformance corpus,
the size and verification cost of a representative Ergo transaction, and
integration in the node. Network activation remains a separate proposal.
