# EIP-0045 development checkpoint — 28 October 2026

The B4 producer reached a scoped local milestone this week. An offline build
produced a generator test binary. A build-time listing found four row-110
selector tests without running them. A raw fixture retained a copy of that
binary without launching it and was independently checked across 294 files,
50 directories and eleven cases. Nine retained inputs matched their source
bytes. These checks establish the fixture and binary inputs for a physical
test; they do not establish a B4 negative result.

The first bounded row-110 selector run reached its 600-second limit before it
published a neutral root. A separate calibration attempt stopped before the
selector because the WSL cgroup did not expose `io.stat`. Both runs remain
recorded as HOLD, with no retry or B4 credit. A successor calibration is under
source review. It keeps the same time limit and is designed to record CPU,
memory and process activity; I/O counters are optional on this host. Those
measurements may distinguish continued work from an observable stall. They
cannot prove which Rust stage was running or that useful cryptographic
progress occurred.

The B8 local boundary is also clearer. An exact signed 262,145-byte real-UTXO
transaction was refused on standalone raw and canonical admission paths, while
the same parsed bytes applied in a complete local block and produced the
expected UTXO state. This does not cover live peer ingress, default deployment
policy, stress or anchored testnet behavior.

The next B4 step is source review of the successor calibration. A measured,
bounded run follows only if that review passes and compute resources are
available. Any neutral root must then be captured byte for byte before
Rust/JVM comparison on that same root.
