# B7 run evidence

Final B7 evidence will use one directory per 32-byte `runId`. Each directory
will contain the exact precommit and anchor records, challenge observation,
proof-output manifests, checkpoints, one aggregate `RunEvidenceV1`, and its
detached pure-Ed25519 signature.

No run evidence exists yet. In particular, this directory does not contain a
test key, placeholder signature, synthetic anchor, or record presented as a
real independent reproduction.
